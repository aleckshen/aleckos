## my projects

1. [uoavc](https://uoavc.wdcc.co.nz/) (university of auckland volleyball club website)

A full-stack site for the University of Auckland Volleyball Club, built with Next.js and Payload CMS. Handles event sign-ups, Stripe-powered social session payments, and gives club executives a CMS dashboard to manage events and members without touching code.

2. [pylib](https://github.com/aleckshen/pylib) (python cli tool)

A command-line tool that takes the decision-making out of choosing a study spot by randomly selecting from all 64 Auckland public libraries. Supports picking any number of libraries at once or listing the full catalogue. Packaged with pyproject.toml and installable globally via pip, exposing pylib as a system-wide command.

3. [aleckos](aleckshen.com) (os themed website)

An operating system styled portfolio built with Next.js, TypeScript and Tailwind. Windows can be dragged, resized, minimised and maximised, with all window state held in a Zustand store and a taskbar tracking whatever is open. Includes a working terminal that parses commands like ls, cat and open, and a file manager that launches each markdown document into its own window.
