# aleckos

My personal website disguised as an operating system. `ssh` into my virtual machines, drag some windows around, and read about me along the way!

> _Live at [aleckshen.com](https://aleckshen.com)_

## How to run locally

Requires [Node 22+](https://nodejs.org) and [pnpm](https://pnpm.io).

```bash
git clone https://github.com/aleckshen/aleckos.git
cd aleckos
pnpm install
pnpm dev
```

Then open <http://localhost:3000>.
